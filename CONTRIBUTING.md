# Contributing

Thanks for wanting to help.

## Reports we'd love

[Open an issue](https://github.com/gkdataio/misconfig/issues) for any of these:

- **A wrong finding.** A setting misconfig flags that's safe in your setup, or a finding with the wrong level. Include the rule ID from the report, such as `CC-BYPASS`, and the relevant lines of the file, with any secrets removed.
- **A missed risk.** A setting or file that puts an agent's machine at risk that misconfig doesn't report.
- **A new agent.** An AI coding agent misconfig doesn't know yet, with where it keeps its settings on macOS, Windows and Linux.
- **Known malware.** A malicious MCP package, editor extension or skill missing from the list, with a link to the report.

Please don't paste whole config files, tokens or anything from someone else's machine into an issue. For a vulnerability, follow [SECURITY.md](SECURITY.md) instead.

## Code contributions

We aren't accepting pull requests yet. For now, all of the code here is owned by GK Data LLC, so it stays under one owner while the project settles. If you've found a fix, describe it in an issue and we'll credit you when it ships.
